# Django JWT Authentication API 🔐

A complete authentication system built using **Django**, **Django REST Framework**, and **Simple JWT**. This API provides secure user authentication with token-based login and features like registration, login, password change/reset, logout, and account deletion.

## 🔧 Tech Stack

- Python
- Django
- Django REST Framework
- Simple JWT
- Django CORS Headers
- SQLite (default, can be replaced with any DB)
- Postman (for testing)

## 🔥 Features Implemented

- [x] User Registration
- [x] JWT Login (Access + Refresh)
- [x] Get Authenticated User Profile
- [x] Change Password
- [x] Send Password Reset Email
- [x] Reset Password via UID and Token
- [x] Logout (Token Blacklisting)
- [x] Account Deletion
- [x] Email Utility with `.env`
- [x] CORS Handling
